## `01` · Sobre mim

Olá! Sou o Carlos, estudante de **Gestão e Programação de Sistemas Informáticos (GPSI)** em Portugal.

Tenho interesse em desenvolvimento web e engenharia de software. Ao longo do curso, tenho explorado diferentes linguagens e criado projetos para consolidar os meus conhecimentos. Também tive experiência prática num estágio na área tecnológica.

Neste momento, estou a reforçar as minhas bases de **JavaScript** e a preparar-me para aprofundar tecnologias como **React** e **TypeScript**, com o objetivo de aprender a desenvolver aplicações completas — do frontend ao backend.
